# Resume Studio · 简历工作室

本地优先的 AI 简历工作台：从简历截图开始，提取并校对内容，再通过有依据的建议整理表达和准备岗位版本。

## 运行

Node.js 22.12+（推荐 Node 22 LTS），npm。

```bash
npm ci
npm run dev
```

打开终端显示的本机地址。开发和预览服务仅监听 127.0.0.1。生产构建为静态文件，可自行部署：

```bash
npm run build
npm run preview
```

## 使用流程

1. 在 **AI 设置** 填写 Base URL、API Key、模型 ID，测试文本连接。Base URL 填接口根目录，例如 `https://your-provider.example/v1`，应用追加 `/chat/completions`；也接受完整的 `/chat/completions` 地址。仅支持兼容该协议的服务。
2. 若模型支持视觉，勾选图片能力。**上传简历截图** 支持最多 5 张 PNG/JPEG/WebP，每张不超过 10MB，可以调整顺序或直接粘贴截图。无视觉模型时可粘贴简历文字。
3. 识别后的内容会建立新的简历。对照 **识别原稿** 检查原图和模糊项，修改字段，再确认已校对。
4. 在 **经历素材** 维护所有公司、项目经历及证据，支持粘贴和导入 TXT/Markdown。分析时可选择素材，也可把素材原文加入简历再整理。
5. 在 **AI 建议** 设置目标语言、招聘市场、岗位描述，选择素材并分析。模型提供理由、参考来源和追问；把追问答案存成素材后可再次分析。
6. 每项修改都有原文/建议对照。确认事实准确后逐条或批量采纳。**修改记录** 可撤回整笔采纳；如果字段之后被修改，将拒绝冲突撤回，避免覆盖新内容。
7. **针对岗位定制** 可识别 JD 截图，校对后创建独立版本。版本建立后点击 AI 分析获取针对性建议。语言切换是分析条件，不会静默翻译或改写原文。
8. 选择经典、现代或紧凑模板，再 **导出 PDF**。在浏览器打印界面选择“保存为 PDF”，建议关闭浏览器页眉页脚；有色模板可启用背景图形。

无需 AI 时，创建、编辑、多份简历、模板、打印和备份仍可使用。虚构示例单独标明，不会自动当作个人经历。

## 数据与隐私

- IndexedDB 保存简历、原图、素材和 AI 修改记录，属于当前浏览器和当前域名。不会自动跨设备同步；清除站点数据会清除它们。
- 使用 **导出全部备份** 定期备份。恢复是追加副本，不覆盖已有文档；重复导入会产生重复副本。备份包含经历和原图，请自行妥善保管。
- API Key 仅保存在页面内存。刷新或关闭页面后消失，不写入数据库、localStorage 或备份。模型地址、模型名、能力开关会保存到本地。
- 只有用户点击连接测试、识别或分析才调用用户配置的接口。截图识别发送选定图片和文字；分析发送当前简历、岗位描述及用户选中的素材。首版没有开发者代理、云端账户或遥测。
- 浏览器直连依赖服务端 CORS。任意 Base URL 不保证可用。可以使用自己的可信兼容网关；应用不会偷偷换服务商。
- 模型生成不能保证事实准确，即使引用了素材，也需要用户核对。所有 AI 替换都需要确认事实后才可采纳。新数字会额外提示。

## 当前范围与限制

- 图片识别、文本解析、建议生成和 JD 识别接入真实兼容 API；没有 Key 时不会模拟成功。
- 文本连接测试不能证明视觉能力；JSON 输出模式需服务商支持，默认关闭。每次请求 90 秒超时，可取消。不支持原生 Anthropic/Gemini 协议，除非经用户自己的兼容网关转换。
- 首版不含 PDF/DOCX 解析、像素级截图版式复刻、云同步、账户、联网检索区域规则或 ATS 通过率保证。
- 日本语/English 是 AI 分析的目标语言，模板固定标题有中英文区分。中文简历与岗位版本需人工校对；地区适配来自所选模型，不是实时核验的法规或招聘规范。
- 字段离开焦点后自动保存。AI 修改历史覆盖 AI 采纳；手动编辑/删除不提供完整 undo 栈，重要修改前请另存副本或备份。
- 模板预览是连续文档；最终分页以浏览器打印为准。超长单条经历可能跨页，更多浏览器/语言组合仍需实测。

## 验证

```bash
npm test
npm run build
npm run test:e2e
```

E2E 默认使用已安装的 macOS Google Chrome；可用 `CHROME_PATH` 指定其他路径。没有 Chrome 时运行 `npx playwright install chromium` 后设置 `USE_PLAYWRIGHT_CHROMIUM=1`。测试会启动 127.0.0.1:4175。

核心测试覆盖原子采纳/撤回、事实确认、过期建议、ID/导入校验、跨文档隔离、事务、备份、URL验证、错误/取消/超时、请求时快照。浏览器测试用模拟 HTTP 响应验证截图/JD的真实应用流程，但**不代表真实模型的识别准确度**；真实服务商与真实简历需在设置 Key 后验证。

调研依据与决策见 [docs/research.md](docs/research.md)，产品边界见 [设计说明](docs/superpowers/specs/2026-09-17-resume-studio-design.md)。

## 代码结构

- `src/domain.ts`：结构校验、简历构建、字段编辑、建议和撤回。
- `src/db.ts`：IndexedDB 事务、原图关联、备份恢复。
- `src/ai.ts`：兼容接口、输入/输出校验、截图提取和建议生成。
- `src/components`：工作台各页面、编辑器、模板、导入与岗位流程。
- `tests` / `e2e`：核心与浏览器测试。

本地开发环境安装依赖时使用过 `--ignore-scripts`；锁文件固定安装结果。项目不会自动部署；可按上面的构建步骤自行部署。
