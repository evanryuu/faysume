# A4 分页预览

右侧默认显示逐页 A4 纸张、页间空隙和“第 X 页 / 共 Y 页”，用户编辑左侧内容时同步更新。保留“直接编辑”模式，切换按钮触发失焦保存，模式在当前浏览器会话内保留。

## 布局

- 预览与导出共用 `.print-layout` 排版规则：A4、14mm 页边距、相同字体与行距。
- 屏幕使用浏览器原生多栏分片，每栏 182mm × 269mm，对应一个打印内容区。每张纸裁切展示对应栏，不按字符数估算分页。
- 预览副本与原始编辑文档共用 `PaperText` 镜像，保留连续空格、空行、末尾换行，避免排版 DOM 不一致。
- 实际打印只显示原始文档，由浏览器分页；测量副本、页码标签、屏幕预览和操作栏不参与打印。
- 纸张根据可用宽度缩放；内容、模板、字体加载或面板尺寸变化后重新测量。

## 可访问性

可见分页副本仅提供页码描述，避免重复整篇正文进入可访问树。分页模式额外提供一份屏幕阅读器可读的完整正文；直接编辑模式仍使用有标签的原生输入控件。

## 验证

使用真实浏览器导出 PDF，逐页比对屏幕上实际可见文字的位置。覆盖三套模板、多页长正文、长中文换行、短经历、标题跟随正文、尾部空行、连续空格、移动端缩放和编辑后页数减少。保留直接编辑、持久化、冲突处理及打印测试。

预览对应 A4、100% 缩放、默认 CSS 页边距、无浏览器页眉页脚。用户在系统打印窗口更改纸型、缩放或边距后，系统设置决定最终分页，界面明确提示这一点。
