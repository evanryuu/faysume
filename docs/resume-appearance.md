# 简历外观设置

调研日期：2026-09-22。

## 常见做法

| 产品                                                                                   | 官方资料中的做法                                                                 | 本项目采用的部分                               |
| -------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- | ---------------------------------------------- |
| [Kickresume](https://www.kickresume.com/en/help-center/resume/)                        | 独立 Design 入口；模板可随时更换并自动保存；支持配色、字体、字号、行距和纸张格式 | 常驻外观入口；模板与外观参数分开；修改自动保存 |
| [FlowCV](https://flowcv.com/)                                                          | 先填内容，再调整布局和设计，最后下载 PDF；简历草稿自动保存，支持不同简历版本     | 外观跟随每份简历保存，复制和备份均保留         |

这些产品共同把简历内容与展示设置分开。用户无需重新填写内容，就可以更换模板和调整视觉效果。

## 本次实现

- 保留经典、现代、紧凑三种模板，将“现代 · 墨绿”更名为“现代 · 色块”。
- 提供六种预设主题色和原生颜色选择器。正文使用深灰色；浅主题色在标题中自动加深，色块内文字自动选择黑色或白色。
- 提供黑体、宋体、等宽字体三组本机字体，以及 9–13 pt 字号、1.3–1.9 倍行距、三档段落间距、10–24 mm 页边距。
- 预览使用固定 A4 宽度后缩放，打印使用同一套字体、颜色、字号与间距规则。外观参数同时应用于分页预览、直接编辑和打印；页边距作用于每一页。
- 设置仅属于当前简历。恢复默认外观保留模板和内容。复制、岗位定制、备份恢复保留设置。
- 旧文档没有 appearance 字段时使用默认值。新字段为可选，不需要数据库或备份版本迁移。

## 范围和限制

本次继续使用 A4 和浏览器“保存为 PDF”，没有增加自定义 CSS、远程字体、背景图、双栏或页面拖拽功能。保留已有的分页预览与直接编辑；调整字号、行距和页边距时同步重新分页。打印请选择 A4、100% 缩放并关闭页眉页脚，保证预览和导出的分页一致。字体使用本机字体，跨设备字形可能不同。浏览器打印请保留背景图形以输出现代模板的色块。

## 交互验收

外观面板是预览区内可折叠的表单，控件有可访问名称，选中配色同时显示勾选标记。移动端设置控件折成两列，外观入口不随设置展开而增高。项目目前没有应用明暗主题切换；纸张始终使用白底。控件操作在本地完成，没有远程加载或权限请求；保存失败沿用编辑器的错误提示。新增界面不依赖动画，并关闭 reduced-motion 下的控件过渡。
